How it works 
def translate(evals):
    dq = evals.get("deal_quality")
    if dq is not None and dq.label == "good":
        return bill(units=1)
    label = dq.label if dq is not None else "none"
    return no_charge(reason="deal_quality=" + label)

Tally reads eval results from Arize AX after each AI response. If deal_quality = good, the customer is billed 1 credit. Otherwise, no charge. Running in shadow mode — no real Stripe charges.
